# Enhance for Android

Photo enhancement. Video stabilization and enhancement. Processing runs on
your phone. The public release candidates are signed APKs for ARM64 Android
devices and are tested on Pixel 8 Pro.

[Download a signed APK](https://github.com/squijello/enhance-ai-releases/releases)

## Install and update with Obtainium

Add this repository's URL in Obtainium and enable **Include prereleases**.
The app appears as **Enhance** from **squijello**. Future updates keep the
same Android package ID and signing certificate.
[Obtainium setup](https://wiki.obtainium.imranr.dev/ui_overview/)

## Source and notices

Enhance includes libde265 1.1.3 under LGPL-3.0-or-later. The corresponding
codec source, GNU licences, third-party notices, and instructions for
replacing the library in a separately signed copy accompany each APK.
You may modify the library and reverse engineer Enhance to debug those
modifications.
